# Operazione Fuori Servizio

*Cinque verifiche. Un premio classificato. Una quantità discutibile di burocrazia.*

Potevamo consegnare un regalo e basta. Abbiamo preferito istituire un dipartimento immaginario, aprire un fascicolo e sottoporre il destinatario a cinque prove. Una gestione delle risorse del tutto ragionevole.

**Operazione Fuori Servizio** è un piccolo gioco fatto su misura per un amico: battute interne, procedure improbabili e una sorpresa da guadagnarsi. Dura circa **5–8 minuti**, salvo ricorsi alla commissione.
